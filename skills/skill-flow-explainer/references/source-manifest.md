# 来源与覆盖
Source classes: W/U/E/A。W = Wiki；U = 用户确认；E = 执行证据；A = Agent 方法建议。
Recompile boundary: 流程还原方法、证据分类或输出契约改变时重新编译相关知识页并回归校验；普通报告运行不修改方法库。
Coverage: bootstrap。U：业务流程与策略分离、纵向流程、固定 HTML 模板、可检查输入输出。A：源码证据分级、覆盖表与结构化渲染契约。E：确定性校验和样例结果保存在开发目录，不随运行包分发。W：本版不宣称使用外部 Wiki 推导。
缺口：复杂委派、多包动态策略与运行时生成流程尚待案例验证。方法变更在维护时编译更新，普通运行不依赖私人知识库。
